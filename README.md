# Embedded Academy

Персональный учебный репозиторий по Embedded-разработке.

## Цель проекта

Изучение языка C, архитектуры компьютера, микроконтроллеров и Embedded-разработки через практические эксперименты, ведение инженерного дневника и создание собственной базы знаний.

Каждая тема сопровождается:
- экспериментами;
- выводами;
- журналом обучения;
- краткими итогами.

## Подход к обучению

Каждая тема изучается через цикл:

1. Формулировка гипотезы.
2. Проведение эксперимента.
3. Анализ результата.
4. Формулировка выводов.
5. Документирование полученных знаний.

Главная цель — не запоминать материал, а понимать причины работы механизмов языка C и компьютерной архитектуры.
