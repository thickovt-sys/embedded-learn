# Topic 01 — Build Process

## Цель

Понять полный путь программы от исходного кода до исполняемого файла.

## Структура

- `journal.md` — дневник изучения темы.
- `notes.md` — основные выводы и теория.
- `experiments/` — исходный код экспериментов.
- `generated/` — файлы, полученные во время экспериментов.
