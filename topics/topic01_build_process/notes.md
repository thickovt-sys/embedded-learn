---

# 21.07.2026

## Эксперимент

### hello_without_include.c

Экспериментальный пример, созданный для проверки реакции компилятора на использование функции `printf()` без подключения заголовочного файла `stdio.h`.

### Результат

Во время компиляции GCC сообщил, что функция `printf()` неизвестна.

### Вывод

Директива `#include` не является частью выполняемой программы.

Она обрабатывается препроцессором ещё до начала компиляции.

---

## Эксперимент

### Работа препроцессора

Команда

```bash
gcc -E hello.c -o hello.i
```

### Результат

- исходный файл увеличился примерно до 1500 строк;
- директива `#include` исчезла;
- вместо неё было подставлено содержимое заголовочных файлов;
- результат всё ещё представляет собой обычный текст на языке C.

### Вывод

Компилятор получает уже обработанный текст программы.

Исходный файл сначала проходит через препроцессор.

# 22.07.2026

## Эксперимент

### Объявление функции без реализации

Создан прототип функции `sum()`, но сама функция не реализована.

### Результат

Компилятор успешно завершил работу.

Линковщик сообщил:

```
undefined reference to 'sum'
```

### Вывод

Компилятору достаточно объявления функции.

Линковщик обязан найти её реализацию.

---

# 23.07.2026

## Эксперимент

### Удаление прототипа

Функция была определена после `main()`, но её предварительное объявление отсутствовало.

### Результат

GCC сообщил:

```
implicit declaration of function 'sum'
```

### Вывод

Компилятор анализирует программу сверху вниз.

Для использования функции до её определения необходимо предварительное объявление.
