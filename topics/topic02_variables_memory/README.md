# Topic 02 — Variables and Memory

## Цель

Понять, что такое переменная с точки зрения памяти компьютера, как она получает адрес и чем отличаются локальные и глобальные переменные.
Понять, как язык C работает с памятью, где располагаются переменные, что происходит при вызове функций и как программа взаимодействует с оперативной памятью во время выполнения.

## Структура

- `journal.md` — дневник изучения темы.
- `notes.md` — основные выводы, эксперименты и результаты.
- `experiments/` — исходный код экспериментов.
