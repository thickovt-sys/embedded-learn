## Эксперимент №3 — Адреса глобальной и локальной переменной

### Код

Вывод адресов:

- глобальной переменной;
- локальной переменной.

### Гипотеза

Предполагал, что при каждом запуске программы адреса обеих переменных будут изменяться.

### Эксперимент

Программа была запущена пять раз.

Полученные результаты показали:

- адрес глобальной переменной оставался одинаковым;
- адрес локальной переменной менялся между запусками.

### Вывод

Глобальные и локальные переменные размещаются по разным правилам.

Также стало очевидно, что память программы разделена на области с разным назначением.

---

## Основные выводы

- Имя переменной необходимо только во время разработки и компиляции.
- Во время выполнения программы процессор работает исключительно с адресами.
- Локальные переменные располагаются в одной области памяти.
- Глобальные и локальные переменные живут по разным правилам.
- Следует различать гарантии языка C и особенности конкретной реализации.
- Для встроенных систем и программ под управлением операционной системы механизм назначения адресов переменным отличается.
