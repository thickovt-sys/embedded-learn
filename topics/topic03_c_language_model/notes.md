## Основная идея темы

Язык C является договором между программистом и компилятором.

Процессор не знает:

- что такое int;
- что такое char;
- что такое float;
- что такое переменная.

Он выполняет только машинные инструкции.

---

## Для чего существуют типы

Тип нужен компилятору.

Он сообщает:

- размер объекта;
- допустимые операции;
- способ интерпретации данных;
- правила генерации машинного кода.

---

## Почему нельзя отказаться от типов

Без системы типов компилятор не сможет:

- автоматически определять размер объектов;
- понимать смысл операций;
- находить множество ошибок ещё до запуска программы.

---

## Первое правило Topic 03

Тип — это описание смысла объекта для компилятора.

Не для процессора.

Не для памяти.

Именно для компилятора.
